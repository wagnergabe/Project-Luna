## Description

In a world where many animals with special needs are often overlooked, Project Luna aims to highlight these wonderful beings who have so much love to give. The app allows users to search for animals with specific needs, making it easier for them to find and connect with pets that require a little extra care and attention.

## Features

- **Search Functionality**: Easily search for animals with special needs based on various criteria.
- **PetFinder API Integration**: Utilizes the PetFinder API to fetch real-time data on animals available for adoption.
- **User-Friendly Interface**: A simple and intuitive interface built with React for easy navigation.
- **Compassionate Mission**: Promotes the idea that every animal, regardless of its condition, deserves a loving home.

## Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/wagnergabe/project-luna.git
    ```

2. Navigate to the project directory:

    ```bash
    cd project-luna
    ```

3. Install the dependencies:

    ```bash
    npm install
    ```

4. Set up your PetFinder API credentials:

    - Sign up for a PetFinder API key [here](https://www.petfinder.com/developers/).
    - Create a `.env` file in the root directory and add your API key:

    ```bash
    REACT_APP_PETFINDER_API_KEY=your_petfinder_api_key_here
    ```

5. Start the development server:

    ```bash
    npm start
    ```

## Usage

- **Search for Animals**: Use the search bar to find animals based on specific needs or conditions.
- **PetFinder API**: Fetches real-time data from the PetFinder API, ensuring that users have access to the latest information on animals available for adoption.
- **Learn About Special Needs**: Get to know more about the unique challenges and wonderful personalities of these animals.
- **Adopt with Love**: Consider adopting an animal with special needs and provide them with the care and love they deserve.
